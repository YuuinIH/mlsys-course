# 课程设计

> **从计算机系统的视角，理解现代机器学习如何真正运行。**

Hello MLSys 面向具备 CS 本科基础的读者，既不是只讲 LLM 的课程，也不是按框架或工具名称罗列知识的技术手册。我们试图让读者理解工作负载、执行机制、资源约束、证据与设计取舍。

内容由三个层次构成：

- [主题地图（Topics）](/topics/)：五个板块、十三个系统主题，限定知识范围，**不是必须填满的章节清单**。
- [专题文章（Essays）](/essays/)：独立回答一个问题，按 L1/L2/L3 标注阅读门槛与成熟度。
- [学习路径（Paths）](/paths/)：从已有文章整理建议阅读顺序，不限制实际写作先后。

推荐的理解主线是：**认识系统 → 让模型训练 → 让模型服务 → 让平台运行 → 让工程可持续**。后训练、状态生命周期、集群资源调度和组织协作都是候选知识主题，但不会只因列入目录就被标记为已完成。

我们不以复刻框架、大型 Lab 或部署平台作为终点。小实验、代码、Profiler、论文、源码与经济估算都可以用来验证想法；结论应陈述适用条件与未知之处。

课程不重讲完整 ML 算法，不把 RAG 应用构建或工具安装大全当作核心目标，也不预设某个系统架构永远优于其他方案。

完整定位、十三个主题、Non-goals 和实践原则以仓库中的 [COURSE_OUTLINE.md](https://github.com/YuuinIH/mlsys-course/blob/main/COURSE_OUTLINE.md) 为准；本站目前有 **5 篇可读初稿**，可从[文章索引](/essays/)开始。

# 1. 服务能响应，怎么判断它够不够快？

> 提纲，正文尚未开始。

先从用户体验说起：第一个字迟迟不出来、输出到一半断断续续、单人很快但多人很慢，分别该看什么？这一节计划引入 TTFT、TPOT、吞吐与延迟分布，用少量直观例子区分“用户觉得快”和“机器处理得多”。

不讨论完整的性能分析方法，也不以单个 tokens/s 数字决定服务好坏。为后续每个调参故事提供一把基本的尺子。

# 学习路径 · Paths

专题文章可以独立阅读。学习路径只是将**现有文章**按照学习目标组织成一种建议顺序，不决定写作顺序或知识存储结构。

## MLSys Fundamentals · 起步路径（建设中）

面向有计算机本科基础、尚未系统了解 MLSys 的读者，目前建议：

1. **[为啥需要 MLSys？](/modules/00-systems-thinking)** · L1：从模型运行到多用户服务，认识为什么 ML 需要系统视角。
2. **[规模效应：从单卡到多卡，从单机到多机](/modules/0X-scaling)** · L2：理解资源规模、扩展效率与成本为何不线性增长。

第二篇完全可以独立阅读。**现在尚不足以构成一门完整的 Fundamentals 课程**；计算与执行、性能测量、训练与推理机制、状态管理和可靠性等领域还需要文章支撑。

## 以后再做什么

等训练、推理或 ML Infrastructure 已有足够多可读文章时，再建立专门路径。目前不发布空路径，不为配齐课时强行增加文章。

如果只想从一个具体问题开始，请使用[专题文章](/essays/)和[主题地图](/topics/)。

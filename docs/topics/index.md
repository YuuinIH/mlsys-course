# 主题地图 · Topics

这是一张课程知识范围的地图，不是需要按顺序学完的章节目录，更不是等待逐项填满的 TODO List。同一篇文章可以出现在多个主题中。

| 主题 | 核心问题 | 当前涉及的文章 |
| --- | --- | --- |
| ML 工作负载 | 模型在执行什么？不同任务为什么给系统不同压力？ | [为啥需要 MLSys？](/modules/00-systems-thinking) |
| 计算与执行 | 模型如何经框架、运行时映射到硬件？ | 尚无正式文章 |
| 性能与测量 | 怎样发现瓶颈，测量是否可信？ | 尚无正式文章 |
| 训练系统 | 显存、并行、通信与扩展效率如何相互制约？ | [规模效应：算力、能力与成本](/modules/0X-scaling) |
| 推理系统 | 一次模型计算如何变成服务？ | [为啥需要 MLSys？](/modules/00-systems-thinking)（导论案例）；[为什么需要专门的 LLM 推理引擎？](/essays/serving-tuning/00-why-inference-engines) |

## 关于空白与交叉

目前有三篇**初稿**具有可读正文，上表中的关联只表示文章**涉及**这一问题，不表示已完整覆盖该专题。

KV Cache 可能同时涉及推理、状态与内存，Checkpoint 可能同时涉及训练、存储与可靠性。这种交叉是帮助建立系统认识的机会。

想立即阅读，去[专题文章](/essays/)；想按建议顺序阅读，去[学习路径](/paths/)。候选方向与边界详见[课程大纲](https://github.com/YuuinIH/mlsys-course/blob/main/COURSE_OUTLINE.md)。
